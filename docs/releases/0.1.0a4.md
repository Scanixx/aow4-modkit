# AoW4 ModKit 0.1.0a4

Convert your existing Age of Wonders 4 mod into readable Python, then continue
developing and maintaining it with AoW4 ModKit.

This preview adds conversion of supported RPK resources and trigger scripts
through the public Python API. It is intended for your own mods and projects
you maintain with their authors' permission. Keep existing credits and license
notices when adapting an authorized project.

## What is new

- Readable trigger analysis, with named operations, conditions and variables.
- Python export and rebuild of supported complete RPKs without a binary template.
- Public resource recipes for strategic spells, dialogs, research/unlocks,
  ascension traits, hero skills, hidden eligibility markers and owned tag books.
- Typed targeter settings, atlas references, localization and notification
  contexts in place of the opaque static values used in earlier migrations.
- Explicit verification against an original RPK after rebuilding. Unsupported
  fields and layouts fail instead of being silently omitted.
- Documentation for moving an existing mod into an editable Python workflow.

The existing authoring workflow remains available: write Python definitions,
validate them and build native mod data and ZIP packages. Python runs during
the build, not inside the game. Older authored static parameters and byte-based
text contexts remain supported.

## Convert your mod

```powershell
python -m aow4modkit export-python YourMod.rpk --scope pack --mod-id YOUR-ORIGINAL-MOD-UUID --output your-mod-python
python -m aow4modkit build-pack your-mod-python --output rebuilt/YourMod.rpk --reference YourMod.rpk
```

Use the original project UUID. Review the generated Python before explicitly
building it. After you intentionally edit behavior, use `--allow-changes` to
allow a rebuild that differs from the original reference. The comparison report
still records the differences; this does not certify in-game behavior.

See [the full RPK guide](https://github.com/Scanixx/aow4-modkit/blob/v0.1.0a4/docs/full-rpk-python-export.md) and
[ascension-resource support](https://github.com/Scanixx/aow4-modkit/blob/v0.1.0a4/docs/ascension-python-export.md) for supported layouts.

## Verification and scope

- 129 SDK tests passed using synthetic fixtures.
- Donate Spell: nine resources, 17 scripts and 8,266 nodes compared, with
  41 transfer/dialog model scenarios passing.
- More Secret Ascension Skills: 11 resources, two scripts and 317 nodes
  compared, with nine victory and 16 AI-startup model scenarios passing.
- Rebuilt RPKs match the previous SDK migrations byte for byte and retain the
  original reference data and script meaning.
- Extracted-wheel builds recreate both RPKs without reading an original RPK,
  requiring game files, or installing the SDK.

This is an experimental preview for the observed AoW4 2.3.x format profile,
requiring Python 3.11 or newer with no third-party runtime dependencies.
Conversion supports the documented resource subset, not every mod or editor
feature. RPK export does not recreate an entire editor project, recover missing
author comments, copy external assets or generate texture atlases. MO
translations and artwork remain separate from the RPK source conversion.

Validation is offline. No new engine, Pantheon, save-game or network multiplayer
test is claimed, and no Python/platform compatibility matrix is claimed.
