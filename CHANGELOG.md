# Changelog

## 0.1.0a3 - strategic spell migration preview

- MIT license for authored code and documentation, included in source and wheel
  distributions and declared in package metadata.
- Named recipes for strategic army spells, targeters, research/unlock resources,
  story events, dialog choices and prepared atlas references.
- Typed named invocation across 105 registry entries, embedded scripts, distinct
  native setup nodes and localized notification-link presets.
- Explicit static parameter preservation, unchanged asset copying, original
  filename case and opt-in preservation of audited dependency order.
- Donate Spell 0.14 migration: nine resources, 17 scripts, 8,266 nodes and 41
  model cases compared independently with the reference release.
- Case-insensitive asset collision checks and rejection of embedded Scripts as
  global triggers. The SDK regression suite contains 43 tests.

## 0.1.0a2 - existing-mod migration preview

- Named recipes for ascension traits, normal hero skills, hidden artifact markers,
  side-property markers and tag books in the observed 2.3 profile.
- Owned forward references, pinned resource IDs/names and explicit definition order.
- Player iteration, persistent variable pools and safely nested guard helpers.
- Optional existing pack/catalog names and separate launcher short descriptions.
- Schema-aware migration of More Secret Ascension Skills 0.4, preserving its
  eleven resource identities, both trigger graphs and all 25 model scenarios.


## 0.1.0a1 - workspace preview

- Standalone observed ACP/RPK core, without legacy mod template dependencies.
- Named class, field, data-type and function constants.
- Typed Python trigger definitions and a documented function registry.
- Read-only inspection, project initialization, validation, build and packaging.
- Target AoW4 2.3.x with generated compatibility text and JSON warnings.
- Optional, independently extensible DLC content catalogs.
- Complete no-DLC Hello Realm example.

Not published. Native game execution and multiplayer are not tested by this
toolkit's offline test suite.
