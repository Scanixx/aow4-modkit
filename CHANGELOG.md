# Changelog

## 0.1.0a4 - prepared preview, not yet published

- Convert supported data from an author's existing RPK into readable public-API Python and continue mod development.
- Integrated trigger analysis, complete supported RPK export and explicit reference comparison.
- Typed static structures and localization/notification contexts; ascension and strategic resource adapters.
- Donate and MSAS original equivalence, model verification and source-only wheel builds.
- Updated author-owned migration guidance, package metadata and [release notes](docs/releases/0.1.0a4.md).
- Includes the local dev0 through dev5 work described below; public 0.1.0a3 remains unchanged.

## 0.1.0a4.dev5 - local development, not released

## 0.1.0a4.dev1 - local development, not released

## 0.1.0a4.dev0 - local development, not released

- Integrated SDK-only decoder for global and story-event trigger scripts.
- Readable outlines, versioned flat JSON, source-byte provenance, explicit
  diagnostics and bounded input/node/depth handling.
- Added `decode` and opt-in `inspect --detail`; metadata inspection stays compatible.
- Native literal getter decoding, deterministic comparison aliases, distinct
  setup types, disabled states and original choice IDs/modes.
- Read-time `FieldTable.field_spans`, without changing serialization.
- Independent Donate comparisons: 17 scripts, 8,266 nodes, 51,478 field ranges
  and 41 model cases for each reference/migrated input. No game test performed.
- Analysis only; buildable Python source export remains future work.
